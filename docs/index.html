Introduction

This assignment looks at whether a model can tell which person wrote a digit from a small image. We worked with a simulated dataset of 25,000 grayscale images, each measuring 28 × 28 pixels. There are 20 fictional writers, and each writer produced digits 0 to 4 across five sessions.

We tested two different approaches. First, we trained a convolutional neural network (CNN) to classify each image into one of 20 writer IDs (closed-set identification). Second, we trained a Siamese network to compare two images and decide whether they came from the same writer (verification). These are not the same task, so we do not treat their scores as directly comparable.

The report first checks the images and metadata, then evaluates the CNN on later sessions from known writers and the Siamese network on writers held out from training. It finishes by comparing what these two evaluations can—and cannot—tell us.

This is a simulated dataset, not real handwriting. The results therefore describe how these models behave on this dataset, not how they would perform on actual handwriting in everyday settings.

2 CNN writer identification

2.1 Prediction task

The response is the writer ID and the input is one 28 × 28 image. The metadata identifies writers as 1–20; the model uses the equivalent zero-based class labels 0–19. With 20 balanced writer classes, chance accuracy is 1/20, or 5%.

2.2 Split and model

The CNN was trained to predict one of 20 writer IDs. We used sessions 1–3 for training, session 4 for choosing the dropout value, and session 5 for the final test result. This is a standard way to test whether the model can still recognise the same writers when the writing comes from a later session.

This split matters because all 20 writers are present in every set. That is necessary for a closed-set classification problem: the model cannot correctly identify a writer it never saw during training. By holding out an entire session, we avoid testing on nearly identical samples from the same recording session and instead check whether the model generalises to later writing samples.

We compared two dropout values as a small, planned hyperparameter check. The model selection was done using the validation session only, and session 5 remained untouched until the final evaluation.

2.3 Results and interpretation

The CNN achieved an overall test accuracy of 0.656 on session 5. For 20 equally balanced classes, random guessing would give a chance accuracy of 0.05. In simple terms, this means the model performed well above chance, but the result should still be read carefully.

For practical identification, the correct writer appeared among the model’s three highest-ranked candidates in 87.1% of test images. Top-three accuracy is not the same as a correct single-name prediction; it describes how often a short candidate list would include the writer.

The digit-specific results were not identical across digits. In this run, digit 2 performed best (0.691), while digit 0 was the weakest (0.598). Since the test set is balanced, per-digit accuracy gives a simple indication of how useful each digit was for identifying writers in this CNN. It is not a pure measure of writer information: digit-specific shape variation and the model’s limitations may also affect the result.

The table above compares the CNN’s accuracy on session 4 and session 5. The held-out test minus validation difference is 0.068. The session-4 result is not an independent estimate because it was used to select the dropout setting; session 5 is the held-out test result. A difference between these scores is consistent with a session shift, but should be interpreted cautiously because it comes from one split and one training run.

This is a closed-set result: the test writers were already known to the model, but their session-5 samples were new to it. That means it does not tell us how the model would do on a completely new person. The row-normalized confusion plot below shows the proportion of each writer’s images assigned to each predicted writer, making consistent confusions easier to spot than in a large count table.

In a second descriptive check, we average the model’s predicted probabilities across randomly selected images of different digits from the same writer in session 5. 3 Siamese same-writer matching

3.1 Pair construction and evaluation split

For the Siamese model, we used writer-disjoint groups: 12 writers for training, four for validation, and four for testing. That means no writer appearing in the validation or test pairs was used in the training pairs. This is a different question from the CNN: here we are asking whether the model can match handwriting from writers it has never seen before.

Each pair uses the same digit on both sides, which helps control for digit identity. Positive pairs contain two different images from the same writer and the same digit, while negative pairs contain images from two different writers but the same digit. The training, validation, and test sets were balanced between positive and negative labels. Because the pair selection sampled across the available sessions, the test set also includes some session variation.

3.2 Network and contrastive loss

Both sides of the network share the same encoder. The model is trained with contrastive loss, which encourages same-writer pairs to sit close together in the embedding space and pushes different-writer pairs further apart. We used a margin of 1, meaning that pairs that are too close when they should be different are penalized. The final distance between two images is computed from the Euclidean distance between their learned embeddings.

3.3 Results and interpretation

On the test writers that were held out from training, the Siamese model reached a balanced accuracy of 0.841 using a distance threshold selected only from the validation writers. Its test ROC-AUC was 0.924: across a randomly selected same-writer and different-writer pair, this measures how often the same-writer pair receives the smaller distance, without fixing a decision threshold.

Sensitivity here means the proportion of same-writer pairs that were correctly accepted, while specificity means the proportion of different-writer pairs that were correctly rejected. Balanced accuracy gives equal importance to both, which is useful here because we do not want a model that is very good at one class but poor at the other.

The session-stratified table compares test pairs whose images come from the same session with pairs spanning different sessions. Cross-session balanced accuracy was 0.827 versus 0.898 for within-session pairs, a difference of -0.071 (cross-session minus same-session). The threshold remains fixed at the value selected on validation writers. This gives a direct, though still sample-dependent, check of whether session changes coincide with a change in matching performance.

This experiment is closer to a verification task on unseen writers than the CNN task. However, it is still based on only four test writers and a sampled set of pairs, so the result should be read as a useful indicator rather than a universal measure of real-world performance.

4 Hyperparameter sensitivity

For the CNN, we compared a small 2 × 2 grid: dropout rates of 0.2 and 0.4 crossed with Adam learning rates of 0.001 and 0.0005. The table and plot report the best session-4 validation accuracy for each setting, the validation loss at that epoch, and when early stopping restored the best weights. The selected model is the one with the highest validation accuracy; it was evaluated on session 5 only after that choice.

Validation accuracy varied by 3.6% across the four CNN settings. This is a useful, limited sensitivity check—not evidence that dropout or learning rate alone caused the difference. Each setting was trained with one random seed, and the small search does not cover other choices such as network depth or embedding size. We held the Siamese architecture and margin fixed to keep the comparison manageable; the session-5 test results were not used to tune either model.

5 Comparison and discussion

The two models answer slightly different questions. The CNN asks: “Which known writer produced this image?” The Siamese model asks: “Do these two images likely come from the same writer?” The CNN achieved 65.6% accuracy on session 5 while identifying writers seen during training. The Siamese model achieved 84.0% balanced accuracy on pairs from writers excluded from training. These figures describe different generalization settings and should not be ranked against each other.

The CNN results by digit show which digits were most useful for writer identification in this run; the sample images provide context for those differences. The five-digit aggregation check also shows whether a short list of different digits can help when identifying a writer. These are descriptive results from this split, not proof that a particular digit is consistently most informative. The Siamese task controls for digit identity by comparing images of the same digit.

For session variation, the CNN’s session-4 and session-5 results compare validation and held-out test performance, while the Siamese table compares same-session and cross-session test pairs. These patterns are descriptive: there is one split and training run, and the Siamese test includes only four writers, so they do not establish that session changes alone caused a performance difference.

5.1 Limitations

  • The images are simulated; performance may not transfer to real handwriting.
  • There are only 20 writers. The Siamese writer-disjoint test set contains four writers, so its result can be sensitive to which writers are held out.
  • Images within a writer-digit-session cell and pairs sharing writers or images are related observations. Image- and pair-level metrics therefore should not be read as if every observation were independent.
  • Only two CNN dropout settings were tested, with one random seed. Report the resulting validation values and treat small differences cautiously.
  • The multi-digit aggregation uses repeated random draws from the same test images. It illustrates the potential value of combining different digits; it is not an additional independent test set.
  • The CNN and Siamese evaluations target different forms of generalization, as described above.
