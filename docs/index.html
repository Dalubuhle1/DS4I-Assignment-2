1 Introduction

This assignment looks at whether a model can tell which person wrote a digit from a small image. We worked with a simulated dataset of 25,000 grayscale images, each measuring 28 × 28 pixels. There are 20 fictional writers, and each writer produced digits 0 to 4 across five sessions.

We tested two different approaches. First, we trained a convolutional neural network (CNN) to classify each image into one of 20 writer IDs. Second, we trained a Siamese network to compare two images and decide whether they came from the same writer. These are not the same task, so we should not treat their scores as directly comparable.

It is important to be realistic here: this is a simulated dataset, not real handwriting. That means the results tell us how these models behave on this dataset, not how they would perform on actual handwriting in everyday settings.

3 2. CNN writer identification

3.1 Split and model

The CNN was trained to predict one of 20 writer IDs. We used sessions 1–3 for training, session 4 for choosing the dropout value, and session 5 for the final test result. This is a standard way to test whether the model can still recognise the same writers when the writing comes from a later session.

This split matters because all 20 writers are present in every set. That is necessary for a closed-set classification problem: the model cannot correctly identify a writer it never saw during training. By holding out an entire session, we avoid testing on nearly identical samples from the same recording session and instead check whether the model generalises to later writing samples.

We compared two dropout values as a small, planned hyperparameter check. The model selection was done using the validation session only, and session 5 remained untouched until the final evaluation.

3.2 Results and interpretation

On the untouched session-5 test set, the CNN correctly identified 60.3% of images (3013 of 5000). With 20 balanced writer classes, uniform random guessing would achieve 5% accuracy, so this result is substantially above that baseline. In practical terms, accuracy is the fraction of later-session images assigned the correct ID among the 20 writers already represented during training; it is not a measure of recognising a previously unseen writer.

Performance differed by digit: digit 3 was classified best (68.3%), while digit 1 was weakest (49.8%), a gap of 18.5 percentage points. In this run, digits 3 and 4 were the strongest and digit 1 the weakest. This suggests that the shape of the digit can affect how much writer-specific evidence the CNN can use, but per-digit accuracy is only an indirect indicator of writer information: it also reflects the model’s errors and the particular test examples. The confusion matrix helps show which writer IDs were mistaken for others.

Session-4 validation accuracy was 0.594 and session-5 test accuracy was 0.603, a test-minus-validation difference of 0.009. The test score is slightly higher, so this run does not show a drop in CNN accuracy from session 4 to session 5. This small difference is not evidence that sessions have no effect: session 4 was used for model selection, and both values come from one split and one training run.

This is a closed-set result: the test writers were known to the model, but their session-5 samples were held out. The session-based split prevents the model from being tested on images from the training sessions, while keeping writer IDs in all sets is necessary for this classification task. It does not estimate performance on a completely new person. The confusion matrix is also useful because overall accuracy can hide specific writer IDs that are often confused.

4 3. Siamese same-writer matching

4.1 Pair construction and evaluation split

For the Siamese model, we used writer-disjoint groups: 12 writers for training, four for validation, and four for testing. No validation or test writer therefore appears in training, so this evaluates whether the model can compare images from writers it has never seen before. This is a different generalisation target from the CNN, where the same known writers appear across the session-based splits.

Each pair uses the same digit on both sides, which controls for digit identity. Positive pairs contain two different images from the same writer and digit; negative pairs contain images from different writers but the same digit. Each split has equal numbers of positive and negative pairs, and pairs are sampled across sessions. The writer-level split prevents direct train/test writer overlap, but sampling pairs repeatedly means individual images and writers can contribute to multiple pairs within a split. Pair-level observations are consequently related rather than independent.

4.2 Network and contrastive loss

Both sides of the network share the same encoder. The model is trained with contrastive loss, which encourages same-writer pairs to sit close together in the embedding space and pushes different-writer pairs further apart. We used a margin of 1, meaning that pairs that are too close when they should be different are penalised. The final distance between two images is computed from the Euclidean distance between their learned embeddings.

4.3 Results and interpretation

On the four test writers held out from training, the Siamese model reached a balanced accuracy of 0.841 using a distance threshold selected only from the validation writers. At this threshold, sensitivity was 0.925 and specificity was 0.757. The model therefore detected most same-writer pairs, but was less successful at rejecting different-writer pairs; the balanced accuracy gives equal weight to those two outcomes rather than allowing the stronger sensitivity to dominate.

Sensitivity here means the proportion of same-writer pairs that were correctly accepted, while specificity means the proportion of different-writer pairs that were correctly rejected. Balanced accuracy gives equal importance to both, which is useful here because we do not want a model that is very good at one class but poor at the other.

The session-stratified table compares test pairs whose images come from the same session with pairs spanning different sessions. Cross-session balanced accuracy was 0.833 versus 0.874 for within-session pairs, a difference of -0.040 (cross-session minus same-session). This is consistent with matching being harder across sessions in this test sample. The threshold was held fixed at the value selected on validation writers, but the comparison is descriptive: the groups differ in size and contain repeated writers/images, and this single sample cannot establish that session changes caused the difference.

This experiment is closer to a verification task on unseen writers than the CNN task. However, it is still based on only four test writers and a sampled set of pairs, so the result should be read as a useful indicator rather than a universal measure of real-world performance.

5 4. Hyperparameter sensitivity

For the CNN, dropout 0.2 achieved a best session-4 validation accuracy of 0.552, while dropout 0.4 achieved 0.594. Based on the displayed rounded values, dropout 0.4 improved validation accuracy by 0.042 (4.2 percentage points). We therefore selected dropout 0.4; the session-5 test set was not used to choose between settings. This is evidence that the result was sensitive to this choice in this run, but the search was deliberately small, used one random seed, and does not establish that 0.4 is generally optimal.

For the Siamese model, we kept the architecture and contrastive margin fixed so the comparison stayed manageable. A more detailed study could explore different margins or embedding sizes, but any such tuning would need to be done only on the validation writers. We should avoid adjusting the model based on the test writers.

6 5. Comparison and discussion

The two models answer different questions. The CNN asks which known writer produced one image and achieved test accuracy of 0.603 on later sessions. The Siamese model asks whether a pair of images from the same digit was written by the same person and achieved balanced accuracy of 0.841 on unseen writers. These scores are not directly interchangeable: the class counts, test writers, split strategy, and decision units differ.

The CNN’s strongest results on digits 3 and 4 and weakest result on digit 1 suggest that some digit shapes carried more useful writer information for this model and test sample. The sampled images show visible differences in stroke shape, size, and weight between writers, while the selected same-writer digit is broadly consistent across sessions. These visual observations are plausible context for the accuracy pattern, not proof that a particular shape caused it. The Siamese task controls for digit identity within each pair, so its result instead reflects how well the embeddings capture writer similarity beyond the shared digit.

For the CNN, session-5 accuracy was 0.009 higher than session-4 validation accuracy, so this run shows no later-session decline for known writers. For Siamese matching, cross-session balanced accuracy was 0.040 lower than within-session balanced accuracy. Together these results do not support a single blanket conclusion that sessions either do or do not affect performance: the CNN and Siamese tasks and writer splits differ, and the Siamese comparison is based on four test writers and one sampled set of pairs. Additional writer/session splits and repeated runs would be needed to establish a stable session effect.

6.1 Limitations

  • The images are simulated; performance may not transfer to real handwriting.
  • There are only 20 writers. The Siamese writer-disjoint test set contains four writers, so its result can be sensitive to which writers are held out.
  • Pair observations share images and writers, so pairs are not independent. Pair-level accuracy does not imply the same precision as an evaluation over a large independent population.
  • Only two CNN dropout settings were tested, with one random seed. Report the resulting validation values and treat small differences cautiously.
  • The CNN and Siamese evaluations target different forms of generalization, as described above.

8 Conclusion

The CNN correctly identified 60.3% of session-5 images from writers seen during training, well above its 5% chance baseline; its accuracy ranged from 49.8% for digit 1 to 68.3% for digit 3. Dropout 0.4 was selected over the alternative after validation, without using the test set. The Siamese model achieved 84.1% balanced accuracy on pairs from unseen writers, with higher sensitivity than specificity, and its cross-session performance was lower than its within-session performance in this sample.

These findings are promising for the simulated data but do not establish real-world handwriting identification performance. The CNN and Siamese results address different tasks, the Siamese test includes only four writers, and the sampled pairs are not independent. The observed session and digit patterns should therefore be treated as findings from this run, not universal effects.
