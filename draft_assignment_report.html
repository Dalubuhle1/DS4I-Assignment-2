1 Introduction

Writer identification asks whether an image of a digit can be assigned to the person who wrote it. This report compares two neural-network approaches on a simulated dataset: a convolutional neural network (CNN) that predicts one of 20 writer IDs, and a Siamese network trained to compare two images and decide whether they came from the same writer.

The dataset contains 25,000 grayscale images of size 28 × 28. Each of 20 simulated writers wrote digits 0–4 in five recording sessions, with 50 repetitions of each writer–digit–session combination. The data are simulated rather than samples of natural handwriting; conclusions therefore concern this dataset and should not be treated as evidence of performance on real handwriting.

We distinguish two generalization questions. For the CNN, we test whether writer identification transfers to a later session for writers represented during training. For the Siamese model, we test whether a learned matching rule transfers to writers excluded from its training pairs. These are different tasks and their scores are not directly interchangeable.

3 2. CNN writer identification

3.1 Split and model

The CNN predicts writer IDs 0–19. We train on sessions 1–3, select the dropout setting using session 4, and report the final evaluation on session 5. All writers occur in each split, which is necessary for this closed-set classification task: a 20-class classifier cannot predict a writer class it never encountered during training. Holding out sessions prevents near-duplicate observations from the same recording session appearing on both sides of the evaluation and measures transfer across sessions for known writers.

We compare two dropout settings as a small, prespecified hyperparameter search. Each candidate is assessed on the same validation session; session 5 is not used for model or threshold selection.

4 3. Siamese same-writer matching

4.1 Pair construction and evaluation split

The Siamese experiment uses writer-disjoint splits: 12 writers for training, four for validation, and four for testing. Thus no writer represented in validation or test pairs contributes images to training pairs. This evaluates whether the matching rule transfers to writers absent from its training pairs; it is distinct from the CNN’s known-writer session-transfer question.

Each pair contains the same digit on both sides, controlling digit identity. Positive pairs use two distinct images from the same writer and digit; negative pairs use images from two different writers but the same digit. The training, validation, and test pair sets are balanced between positive and negative labels. A pair’s session combination is sampled from the available images, so the test set includes session variation.

4.2 Network and contrastive loss

Both branches share one encoder. The network is trained with contrastive loss: same-writer pairs (label 1) are encouraged to have small embedding distances, while different-writer pairs (label 0) are penalized when their distance is below a margin of 1. The model outputs the difference between the two embeddings; the loss and evaluation convert this to Euclidean distance.

4.3 Results and interpretation

On pairs from writers excluded from model training, test balanced accuracy is 0.841 at a distance threshold selected using validation writers only. Sensitivity is the fraction of same-writer pairs correctly accepted; specificity is the fraction of different-writer pairs correctly rejected. Balanced accuracy gives equal weight to these two rates. The threshold is selected on validation data and then held fixed for test evaluation.

This matching experiment is closer to verification of previously unseen writers than the CNN experiment, but it uses only four test writers and sampled pairs. Results may vary with the writer split and pair sample. They should be interpreted alongside the pair-construction protocol, not as a universal biometric error rate.

5 4. Hyperparameter sensitivity

For the CNN, the two dropout candidates and their session-4 validation accuracies are reported above. The chosen model is the one with the higher validation accuracy. The test set is evaluated only after selection. The difference between the two validation scores provides a limited sensitivity check; it is not a comprehensive search and does not account for variation across random seeds.

For the Siamese model, we fixed the architecture and contrastive margin to keep the comparison bounded. A further study could vary the margin or embedding dimension, but would need to select settings only on validation writers. Avoid repeated test-set tuning.

6 5. Comparison and discussion

The CNN answers “which known writer produced this image?” and the Siamese model answers “do these two images share a writer?” The CNN test accuracy (0.603) is measured on later-session images from known writers; the Siamese balanced accuracy (0.841) is measured on pairs from writers excluded from training. Because the split designs and prediction targets differ, the scores should not be ranked as though they measured identical performance.

Use the digit-specific CNN results to identify which digits were easier for writer classification in this experiment. Explain the observed pattern using the image examples, while noting that each digit has its own geometry and that the same-digit pairing in the Siamese task deliberately controls for digit identity. Do not claim that a digit is inherently more writer-informative beyond this simulated dataset and evaluation.

The CNN split places sessions 1–3 in training and session 5 in testing, with session 4 for model selection. The Siamese pair construction samples images across the available sessions for the held-out writers. Discuss whether the displayed samples suggest session-related changes, and be cautious: this design does not provide a separate numerical estimate of the effect of session on Siamese matching. A direct session-effect analysis would require a prespecified comparison of within-session and cross-session pairs.

6.1 Limitations

  • The images are simulated; performance may not transfer to real handwriting.
  • There are only 20 writers. The Siamese writer-disjoint test set contains four writers, so its result can be sensitive to which writers are held out.
  • Pair observations share images and writers, so pairs are not independent. Pair-level accuracy does not imply the same precision as an evaluation over a large independent population.
  • Only two CNN dropout settings were tested, with one random seed. Report the resulting validation values and treat small differences cautiously.
  • The CNN and Siamese evaluations target different forms of generalization, as described above.
