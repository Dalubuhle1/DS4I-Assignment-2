1 Introduction

This assignment looks at whether a model can tell which person wrote a digit from a small image. We worked with a simulated dataset of 25,000 grayscale images, each measuring 28 × 28 pixels. There are 20 fictional writers, and each writer produced digits 0 to 4 across five sessions.

We tested two different approaches. First, we trained a convolutional neural network (CNN) to classify each image into one of 20 writer IDs. Second, we trained a Siamese network to compare two images and decide whether they came from the same writer. These are not the same task, so we should not treat their scores as directly comparable.

It is important to be realistic here: this is a simulated dataset, not real handwriting. That means the results tell us how these models behave on this dataset, not how they would perform on actual handwriting in everyday settings.

3 2. CNN writer identification

3.1 Split and model

The CNN was trained to predict one of 20 writer IDs. We used sessions 1–3 for training, session 4 for choosing the dropout value, and session 5 for the final test result. This is a standard way to test whether the model can still recognise the same writers when the writing comes from a later session.

This split matters because all 20 writers are present in every set. That is necessary for a closed-set classification problem: the model cannot correctly identify a writer it never saw during training. By holding out an entire session, we avoid testing on nearly identical samples from the same recording session and instead check whether the model generalises to later writing samples.

We compared two dropout values as a small, planned hyperparameter check. The model selection was done using the validation session only, and session 5 remained untouched until the final evaluation.

3.2 Results and interpretation

The CNN achieved an overall test accuracy of 0.603 on session 5. For 20 equally balanced classes, random guessing would give a chance accuracy of 0.05. In simple terms, this means the model performed well above chance, but the result should still be read carefully.

The digit-specific results were not identical across digits. In this run, digit 3 performed best (0.683), while digit 1 was the weakest (0.498). These are descriptive results from one split and one training run, so they should be considered alongside the sample images rather than treated as a universal statement that one digit is always easier to classify.

This is a closed-set result: the test writers were already known to the model, but their session-5 samples were new to it. That means it does not tell us how the model would do on a completely new person. 4 3. Siamese same-writer matching

4.1 Pair construction and evaluation split

For the Siamese model, we used writer-disjoint groups: 12 writers for training, four for validation, and four for testing. That means no writer appearing in the validation or test pairs was used in the training pairs. This is a different question from the CNN: here we are asking whether the model can match handwriting from writers it has never seen before.

Each pair uses the same digit on both sides, which helps control for digit identity. Positive pairs contain two different images from the same writer and the same digit, while negative pairs contain images from two different writers but the same digit. The training, validation, and test sets were balanced between positive and negative labels. Because the pair selection sampled across the available sessions, the test set also includes some session variation.

4.2 Network and contrastive loss

Both sides of the network share the same encoder. The model is trained with contrastive loss, which encourages same-writer pairs to sit close together in the embedding space and pushes different-writer pairs further apart. We used a margin of 1, meaning that pairs that are too close when they should be different are penalised. The final distance between two images is computed from the Euclidean distance between their learned embeddings.

4.3 Results and interpretation

On the test writers that were held out from training, the Siamese model reached a balanced accuracy of 0.841 using a distance threshold selected only from the validation writers. In other words, it was able to tell when two images were likely written by the same person, while also rejecting pairs from different writers.

Sensitivity here means the proportion of same-writer pairs that were correctly accepted, while specificity means the proportion of different-writer pairs that were correctly rejected. Balanced accuracy gives equal importance to both, which is useful here because we do not want a model that is very good at one class but poor at the other.

This experiment is closer to a verification task on unseen writers than the CNN task. However, it is still based on only four test writers and a sampled set of pairs, so the result should be read as a useful indicator rather than a universal measure of real-world performance.

5 4. Hyperparameter sensitivity

For the CNN, we compared two dropout values and recorded their validation accuracy on session 4. The model with the higher validation score was selected, and the session-5 test set was only used after that decision. This gives a simple sensitivity check, but it is limited because we only tested two settings and used one random seed.

For the Siamese model, we kept the architecture and contrastive margin fixed so the comparison stayed manageable. A more detailed study could explore different margins or embedding sizes, but any such tuning would need to be done only on the validation writers. We should avoid adjusting the model based on the test writers.

6 5. Comparison and discussion

The two models answer slightly different questions. The CNN asks: “Which known writer produced this image?” The Siamese model asks: “Do these two images likely come from the same writer?” Because of this, the CNN score (0.603) and the Siamese balanced accuracy (0.841) are not directly interchangeable.

Looking at the digit-specific CNN results helps us see which digits were easier to classify in this experiment. The pattern should be explained using the example images, because each digit has its own shape and some are naturally more distinctive than others. The Siamese task also controls for digit identity by comparing images of the same digit only, so it is not measuring general digit difficulty in the same way.

The CNN split used sessions 1–3 for training, session 4 for validation, and session 5 for testing. The Siamese model, by contrast, sampled pairs across available sessions for withheld writers. Looking at the sample images, we should consider whether there are visible session effects, but we should be careful not to overstate this. This design was not built to give a separate numerical estimate of session effect, and a proper session analysis would need a more explicit within-session versus cross-session comparison.

6.1 Limitations

  • The images are simulated; performance may not transfer to real handwriting.
  • There are only 20 writers. The Siamese writer-disjoint test set contains four writers, so its result can be sensitive to which writers are held out.
  • Pair observations share images and writers, so pairs are not independent. Pair-level accuracy does not imply the same precision as an evaluation over a large independent population.
  • Only two CNN dropout settings were tested, with one random seed. Report the resulting validation values and treat small differences cautiously.
  • The CNN and Siamese evaluations target different forms of generalization, as described above.

8 Conclusion

This assignment compared two different ways of identifying writers from simulated handwriting images. The CNN was used to classify a digit image into one of 20 known writers, while the Siamese model was used to decide whether two images were likely written by the same person. The results show that both approaches can work on this dataset, but the performance depends heavily on the evaluation setup and the nature of the task.

The main lesson is that these models are not directly comparable because they are solving different problems. The CNN tests recognition of known writers across later sessions, while the Siamese model tests matching ability for writers it has not seen before. The real value of this analysis is that it shows how model design, data splits, and evaluation choices shape the result.
